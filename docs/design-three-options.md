# RUN Finish Planner 構成・デザイン改善の3案
PCSAPO / マキシ企画

## 現在の評価
事前に大会情報を整え、計画し、携帯カードに出力する目的は明確です。「大会→計画→カード→保存」の4区分、緑を中心とした配色、大きな数字、二つ折りカードは方向性が揃っています。

改善余地は情報の密度と操作の優先順位です。入力欄やボタンが広く、同じ重要度に見える要素が多いため、スマートフォンではスクロールが増えます。「保存」にはバックアップ、削除済み、画像設定が混在します。計画画面では目標やペース変更の結果と、編集している場所が離れることがあります。

私の画面レビューによる評価は、目的との一致4/5、視覚的な統一感4/5、操作効率3/5です。実際のランナーによる利用テストの点数ではありません。確信度は中です。

| 案 | 画面構成と見た目 | 実際の使い方 | 改修量・注意点 |
|---|---|---|---|
| 1. レース準備ノート（推奨） | 現在の緑と白、4タブを継承。大会名・目標・保存状態を上部にまとめる。主要操作だけ濃い緑、補助操作は小さな文字ボタンにする。 | 大会を選択→目標を入力→下部の「カードを確認」へ。関門や補正は必要時だけ開く。保存画面も「バックアップ」「削除済み」「設定」の折りたたみにする。 | 小〜中。既存操作を維持でき、保守が容易。現在のアプリを磨く案。 |
| 2. ペース設計デスク | 白・チャコール・緑で数字を主役にする。PCでは左に設定、右にカードと通過表。スマートフォンでは結果の要約を固定し、編集を下に配置する。 | 目標、前後半差、停止時間を変更し、カードへの影響を同じ画面で確認。比較案は必要時に展開する。 | 中〜大。上級者の比較作業に向くが、小画面で固定表示が場所を取りすぎない設計が必要。 |

## 推奨する進め方
案1を基盤にし、案2の「変更結果がすぐ分かる要約」だけを加えることを推奨します。新しい管理画面や走行中の操作は増やさず、事前計画とカード出力に集中できます。全面的な案2・案3の実装は今回行っていません。

次の改善優先順位は、保存画面の整理、スマートフォンでの主要操作の位置統一、目標変更後の結果要約です。大会データの更新・確認日も、販売前に運用として継続できる体制が必要です。

販売前の判断は、複数のランナーに「大会選択から印刷まで」を実際に使ってもらい、迷った場所・完了までの時間・印刷の読みやすさを確認して行います。現時点では利用者の好みや改善効果の数値はわかりません。
