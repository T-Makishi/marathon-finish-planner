# 2.2.9 沖縄県大会カタログ拡充設計

- 対象：2026年・2027年の沖縄県内の距離が定まった個人走。開催済みの2026年大会も年度を明示して収録する。
- 既存NAHA・尚巴志の詳細データは維持。石垣島・沖縄100Kの年度未定ひな型を公式年度データへ置換する。保存済みの利用者計画は変更しない。
- 開催年・種目ごとに一意なID/slug。公式掲載距離を維持し、非標準距離を標準ハーフへ丸めない。
- 公式大会サイト、主催自治体、主催者の申込ページ、公的観光情報を照合。URLと確認日を各種目に保存。未確認の開始・制限時間はnull。矛盾する時間は採用せず注意事項に明示。
- 日をまたぐ関門は経過分で保存し、既存のインポート処理で日数と時計時刻に変換する。
- 開催休止・中止、2027年の種目未発表、駅伝・時間走・歩行のみは登録せず調査記録に残す。
- 検証：ID重複、年度、種目数、実距離、未確認値、400km/72時間の計算・日跨ぎ関門、既存計画の保持、検索・選択・保存・印刷データ生成、Web/iOSビルド。
- 公開：既存GitHub Pagesに2.2.9を公開し、配信された版を確認する。
