# 2.2.21 スマートフォン印刷の白紙対策

- 画面用A4枠と印刷用ページの高さを分離する。印刷時は固定高さ296.5mmを解除し、内容の高さで配置する。
- 印刷時はページ末尾の強制改ページを解除し、2枚目以降の先頭だけで改ページする。ブラウザの余白で内容が収まらず、空白の残り枠が別ページへ送られる余地を減らす。
- @page余白を10mm、ページフッターを通常配置へ変更。カードのmm寸法・文字サイズ・切り取り線は維持し、ページ説明の行間と余白のみ整理する。
- 単頁・複数頁・最大高さカード・追加資料の出力を検証する。Safari/iOS実機未確認は明記する。
