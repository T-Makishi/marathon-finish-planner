# 手首用カード2種類の設計

- 原因：比較を選ぶとポケットへ強制変更され、手首用の選択肢が消える。
- 印刷内容と形状の選択を独立させる。手首用は本番案の累計時間、挑戦・本命・堅実の3目標比較、両方を選択可能にする。
- 本番案は幅50mm、比較は3列の視認性のため幅70mm。高さ180〜195mmで自動調整する。
- 手首用には大会名・日付・時間基準・距離別累計時間のみを配置。移動平均と配分説明、別基準の総時間は省く。関門は既存の表示設定を尊重する。
- 1km・5km刻み・中間点・ゴールを保持。両方の場合は独立した切り取り枠にし、折り線は付けない。
- A4内の横幅を計算して配置し、入りきらないカードだけ次ページへ送る。ポケットの二つ折りは維持する。
- 保存形式・計算式は変更しない。各モード、NAHA相当、印刷PDFを検証後に公開する。
