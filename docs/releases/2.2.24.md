# 2.2.24 — 使い方動画

- 現在の依頼に基づき、採用済み女性音声の「手首用」を音声入力では「てくび用」に指定。画面・字幕は「手首用」を維持。
- 約93秒のスマホ版とPC版を「使い方」冒頭に追加。ロング版は公開しない。
- 狭い画面はスマホ版を初期選択。手動切替、インライン再生、全画面の標準動画操作に対応。
- 自動再生なし・preload=none。別の版に切り替えた場合や使い方から離れた場合は動画を破棄し停止。
- MP4はH.264/AAC。字幕を映像に焼き込み。再生時のみ通信を使用。
- 既存計画データ、計算処理、保存処理は変更なし。

検証：型検査成功、既存109テスト成功、Webビルド成功。2本の全ファイルデコード成功。ChromeでPC版・スマホ版の再生と92.833秒の長さを確認。390px幅でスマホ版の初期選択、preload=none、自動再生OFFを確認。画面移動で動画要素がなくなることを確認。

音声は読みをひらがなで指定して再生成。主観的な声質の聴取評価は未実施。

プロジェクト：PCS-APP-0002。変更承認：現在のユーザー依頼（音声修正後に使い方へ設置）、既存の公開指示。登録済み元作業フォルダには未コミット変更があるため、従来の公開用チェックアウトのみを使用。Drive・Obsidian・NotebookLMの変更なし。
