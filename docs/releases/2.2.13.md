# 2.2.13 携帯カードの全地点表示と可変高

## 変更内容

- 地点を省略する表示モードを廃止し、1km、5km、10km以降5km刻み、中間点、ゴールを常に表示する従来仕様へ戻した。
- 携帯カードへの関門表示を選択できるようにし、制限完走の計画では関門を常に表示する。
- 幅85mmと文字サイズを維持したまま、情報量に応じてカード高を135〜195mmで自動調整する。
- 本番案と3目標比較を同じ地点・同じ高さの一体型にし、中央で二つ折りにできる外周線と折り線を維持した。
- 195mmを超える特殊な計画だけは、地点を欠落させず複数枚へ分割する。
- 2.2.12の保存データはそのまま読み込み、廃止した地点表示設定だけを出力に使用しない。

## 検証結果

- 回帰テスト102/102、型検査、Web/iOSエクスポートに成功した。
- 第40回記念NAHAマラソン相当の標準11地点と8関門を、展開170 × 194mm、折り後85 × 194mmの携帯カード1枚へ収めた。
- Chromeの実印刷PDFでA4縦1ページとなり、白紙ページ、文字の欠落・重なり・はみ出しがないことを目視確認した。
- ローカル配布版で関門表示の切替、前回仕様の地点構成、動的な寸法案内、印刷プレビューを確認した。
- 管理対象はPCS-APP-0002。現依頼に基づく実装・公開であり、追加承認IDの発行、管理状態の変更、Drive・Obsidian・NotebookLMへの書き込みは対象外。
