# 2.2.17 続きカードの二つ折り設計

- ポケット用で隣り合う2面を同じ高さ（長い方）に統一し、1つの外周切り取り線と中央折り線を使う。
- 本番案＋比較は従来どおり同一区間で組む。比較のみ・本番案のみの続きはページ順に2面ずつ組む。奇数の最後は単独カード。
- 表裏の見出しはカード種別と分割番号を反映する。携帯カード枚数は切り取り後の実物の枚数を示す。
- 文字・行サイズと地点情報を維持。短い側は下余白を増やし、下部説明の位置を長い側に揃える。手首用は既存の独立切り取りを維持。
- 2分割・3分割・本番案＋比較の回帰検証、Web/iOS出力、名古屋の地点構成でPDF確認後に公開。
