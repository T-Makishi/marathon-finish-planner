# 2.2.18 印刷プレビューの使い方

- カードの種類、携帯方法、時間・関門、追加資料、プレビュー、印刷・PDFの6項目を折りたたみ式で解説。
- カード枚数と用紙ページ数、画面拡大と印刷倍率の違い、二つ折り、紙の節約、50mm目盛りの確認を追加。
- 実際の印刷出力例を掲載（説明用サンプル値と明記）。古いカード設定の画像はカード説明に表示しない。
- カードから説明を直接開き、カード画面へ戻れる導線を追加。続きの二つ折りの案内も実際のレイアウト判定に統一。
- 型検査、Web/iOS出力成功。Chromeの390px幅で説明の開閉・カード画面との往復を確認。Safari実機は未確認。
- PCS-APP-0002。今回の指示に基づく使い方と公開の更新、追加承認IDなし。計算・保存データ・外部管理サービスへの変更なし。
