# 2.2.8 計画0件からの登録を修正

原因：大会入力フォームが選択中の計画の存在を前提に描画されており、最後の計画を削除すると新規登録ボタンが入力フォームを開けなかった。

修正：
- 入力フォームを共通化し、計画0件でも大会一覧・新規登録を表示する。
- 計画・カードの空状態からも大会入力へ遷移する。
- 保存・使い方タブには無関係な空状態案内を表示しない。
- 完全削除時、復元用コピーに不要な空計画を自動作成しない。

検証：
- スマートフォン幅390pxのブラウザで最後の計画削除、新規登録、保存、再読み込み、大会一覧からの追加、削除済み計画の復元を確認。
- 自動テスト94件成功。完全削除→0件維持→再読込→バックアップ検証→新規登録を追加。
- 型チェック、Webビルド成功。
- iPhone実機のSafariは直接操作していない。共通描画条件とデータ処理を修正。

公開：既存GitHub Pages。既存の計画は保持。開発元の未コミット変更・外部管理台帳・Drive・Obsidian・NotebookLMは変更しない。
