# 2.2.22 複数タブの保存同期

## 修正
- タブを開いた際の無変更保存を省略し、不要な保存競合を解消。
- 同じブラウザ・同じ公開URLのタブ間で、保存済み内容を自動取得。
- 未保存の編集や大会情報の編集中は外部更新を取り込まず、古い内容の上書きを世代チェックで拒否。
- 初期読み込み・初回サンプル作成もWeb Locksの排他処理に統合。
- 完全削除時の両保存コピー更新を維持。

## 検証
- 自動テスト109件成功（無変更保存、相互更新、未保存編集保護、競合拒否、削除・完全削除同期を含む）。
- TypeScript検証、Webビルド、iOSバンドル生成成功。
- Chromeのローカル検証環境で、タブAの大会新規登録を既存タブBが自動表示、Bから名称変更後Aにも自動反映。
- 3つ目の新規タブで同じ保存内容を確認。コンソールエラーなし。

## 範囲と制限
- ユーザーが見た過去の消失そのものは再現証拠がなく、断定しない。
- 同時に異なるタブを編集し保存が競合した場合は、上書きせずエラーで知らせる。未保存内容はバックアップ可能。
- 別ブラウザ・別プロファイル・別端末への同期機能ではない。
- 公開環境のユーザーデータは編集・削除していない。中央台帳・外部サービス変更なし。
