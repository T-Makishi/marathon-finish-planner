# 2.2.2 数値入力をプルダウンへ統一
PCSAPO / マキシ企画

## 設計
- 数値の手入力欄と「数字で選択」開閉ボタンを撤去し、数字のプルダウンを常時表示する。大会名・メモ・URLは文字入力のまま。
- 時刻・所要時間・ペースは単位別選択。停止時間・余裕・補正などは数値候補から選択。補正は負数にも対応する。
- 距離・開始地点・終了地点・停止地点はkmと端数mを選択し、保存時にkmへ統合する。既存の小数精度と候補外の現在値を保持する。
- 任意項目は「未設定」で空欄に戻せる。表示するだけでは値を変更しない。
- 計算・保存形式は変更しない。停止・補正・通常の時間と新規登録をブラウザーで検証する。

## 検証結果
- 自動テスト90件成功、TypeScript・Web・iOS向けビルド成功。距離分解・再結合、候補外の現在値、小数・負数保持を確認。
- ブラウザーで停止地点5km+200m、20秒、補正-5秒/kmを選択。再読み込み後も停止の値を保持。目標時間の3プルダウンと数値手入力欄の撤去を確認。
- 現在の公開アプリのみ更新。元の作業フォルダー、管理台帳、外部資料サービスは変更なし。実機iPhone操作は未検証。
