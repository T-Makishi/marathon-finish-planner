## ストア掲載原稿案

**名称**：RUN Finish Planner

**サブタイトル**：大会前のペース計画と早見カード

**説明**：大会前に、自分の走り方を一枚にまとめる。RUN Finish Plannerは、目標タイム、前後半の配分、コース補正、補給の停止時間を組み合わせ、通過予定を確認する事前計画アプリです。一定ペースや後半を速くする配分を選び、必要な区間は自分で調整できます。登録した関門と完走制限を確認し、1案を大きく表示したカード、または3つの目標タイムを比べるカードを作成します。大会当日は印刷したカードと時計で予定を確認してください。大会情報のひな型は、最新の公式要項と照合してから利用します。

**キーワード案**：マラソン,ペース,関門,完走,ランニング,レース,計画,ペース表

**サポートURL**：https://t-makishi.github.io/marathon-finish-planner/support.html

**プライバシーURL**：https://t-makishi.github.io/marathon-finish-planner/privacy.html

**審査担当者への説明案**：アカウント登録不要の事前計画アプリです。起動時の初期計画で目標と配分を変更し、「カード」からPDFの生成と共有を試せます。位置情報や走行記録は使用しません。ネットタイムと大会号砲からの時間を区別します。大会カタログは確認用のひな型で、最新要項の再確認を案内します。
