# 2.1.9 追加資料の用紙節約
PCSAPO / マキシ企画

## 設計
- 関門・制限時間、補給・停止、コース補正の順序で、選択済みかつ内容がある表だけを追加資料へ配置する。
- A4縦の共通ヘッダー・フッターを除いた240mmを上限とし、表題・説明・列見出し・行・余白を計算する。文字サイズは維持する。
- 小さな表は同じページへまとめる。残り領域に収まらない小さな表は次ページへ、大きな表は行単位で分割し、続きの表題と列見出しを再表示する。
- 携帯カードの切り取り寸法・表裏の構成を維持し、追加資料のページ数とプレビューは新しい配置から生成する。
- 少量3表の集約、多量の分割、行の欠落・重複、非選択・空表の除外、実表示の余白を検証する。

## 検証・変更範囲
- 自動テスト84件成功。少量3表の1ページ集約、多量混在時の順序・行保持・高さ上限、空表と非選択表の除外を確認。
- TypeScript検査・Webビルド・差分検査成功。ブラウザーで3表の同居、通常の文字サイズ、フッターとの非重複と横のはみ出しなしを確認。
- 対象はカード生成・説明文・テスト・バージョン。既存の利用者データ、元の作業フォルダー、管理台帳、Drive、Obsidianは変更していない。
- 公開は既存GitHub Pagesへ実施。実機プリンターでの印刷は未検証。
