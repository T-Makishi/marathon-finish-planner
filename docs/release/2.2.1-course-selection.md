# 2.2.1 コース選択画面
PCSAPO / マキシ企画

## 設計
- 見出しをコース選択へ変更。保存済み計画は初期表示・大会タブへの移動・選択後も展開する。
- 大会と計画は通常閉じた新規登録フォーム。保存済み計画とは独立した下書きを使用し、登録成功後に空欄へ戻して閉じる。未登録の空計画を作らない。
- 保存済み計画の編集は「選択中の大会情報を編集」から明示的に開く。基本情報だけを更新し、ペース・関門・補給設定を保持する。
- 保存を確認した場合だけフォームを閉じる。失敗時は入力を保持。登録と編集のボタン名・完了表示を分ける。

## 検証結果
- 自動テスト89件成功、TypeScript・Webビルド成功。空フォーム、登録時の既存計画保持、編集時の最新ペース・停止設定保持を検証。
- ブラウザーで初期一覧展開、フォーム初期閉鎖、登録→一覧追加→閉鎖→再展開で空欄、既存編集、保存・再読み込みを確認。
- 対象は大会画面と登録処理。元の作業フォルダー、管理台帳、外部資料サービスは変更していない。実機iPhoneの操作は未検証。
