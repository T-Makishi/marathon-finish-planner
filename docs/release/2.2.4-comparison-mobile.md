# 2.2.4 スマートフォンの比較目標入力
PCSAPO / マキシ企画

## 設計
- 原因：3目標の親行が折り返し可能で、各目標の最小幅が115pxのため、スマートフォンで先頭2目標が横に並び、各時分秒の末尾だけ折り返される。
- 幅820px未満では比較目標を縦3段とし、各目標に横幅全体を割り当てる。各段の時分秒は3列を保つ。
- PCでは従来の3目標横並びを維持。数値・計算・保存形式は変更しない。
- 390pxと320pxの画面で、全目標の時分秒が同じ高さに並ぶことを確認する。

## 検証
- 390px・320pxのブラウザー幅で、各目標の時分秒3欄が同じ高さで横並びになることを測定。3目標の欄幅も一致。
- 時間表記を「時」に短縮し、数値選択内の余白も縮小して文字切れを抑制。
- TypeScript検査・Webビルド成功。利用者データと計算処理は変更なし。元の作業フォルダー、管理台帳、外部資料サービスは変更なし。
