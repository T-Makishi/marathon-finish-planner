# 2.0.1 オープニング復元

2026-09-12 / PCSAPO / マキシ企画

2.0で外した旧版のオープニングを復元。既存の背景写真、Run to Chebisの白ロゴ、移動アニメーション、約2.6秒後の自動遷移、タップでのスキップを再利用する。計画画面の再描画やタブ切替では繰り返し表示しない。「保存 → オープニングを再表示」から再生できる。

旧版の背景設定が保管データに残っている場合は参照し、読込み失敗時は標準背景に戻す。画像読込み・アクセシビリティ情報取得が終わらない場合も計画画面を塞ぎ続けない。動きを減らす設定では静止表示する。

確認：型チェック、Webビルド、既存58項目の自動テスト。ブラウザで標準背景と白ロゴ、自動終了、再表示、タップスキップ、終了後の保存済み計画を確認。
