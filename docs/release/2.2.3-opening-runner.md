# 2.2.3 男性ランナーの標準オープニング画像
PCSAPO / マキシ企画

## 設計
- 男性ランナー1名が海沿いを走るモノクロ縦長画像を生成し、標準背景に設定する。
- 生成原本は保持し、配信用JPEGに変換して既存の標準背景ファイルを置き換える。旧画像はGit履歴から回復可能。
- 設定画面の標準プレビューとオープニングは同じ画像を参照する。
- 利用者が設定した独自画像は保持。「標準画像に戻す」で新しい画像に切り替えられる。
- ロゴ・スキップ・自動終了の挙動は維持する。

## 検証結果
- 生成画像は男性1名・モノクロ・縦長。配信用画像は436,560バイト前後（約426KB）。原本は生成画像フォルダーに保持。
- Web・iOS向けビルド成功。ブラウザー390×844で標準背景と白いロゴの重なりを確認し、自動終了後に通常画面へ戻ることを確認。
- 公開アプリの標準画像と版番号のみ変更。利用者の独自背景設定、元の作業フォルダー、管理台帳、外部資料サービスは変更しない。実機iPhoneでの表示は未確認。
