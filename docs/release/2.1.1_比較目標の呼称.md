# 2.1.1 比較目標の呼称

2026-09-12 / PCSAPO / マキシ企画

## 設計
- 比較A/B/Cを「挑戦目標／本命目標／堅実目標」に統一する。競技団体が定めた公式呼称とは表現しない。
- 挑戦は好条件で狙うタイム、本命は比較の中心、堅実は状況に応じて切り替えるタイム。堅実は完走や安全を保証する意味ではない。
- 入力・カード見出し・表の列・別紙の説明・エラーを共通定義から表示する。カードの狭い列では「挑戦／本命／堅実」に短縮する。
- タイムは挑戦＜本命＜堅実の順とし、逆順や同値は案内を出して印刷を止める。既存タイムの書き換え・並べ替えはしない。
- 本番案と比較の本命が独立していることを説明する。現目標を使う場合は既存の±5分ボタンから設定する。
- 保存形式・計算方法・カードの実寸・ページ配分は維持する。

## 検証予定
- 既存計算・印刷・保存検証、順序不正の検出、HTMLから旧ラベルがなくなること。
- Webビルド、公開処理、公開画面で新ラベルとプレビューを確認する。
