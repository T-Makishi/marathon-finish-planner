# RUN Finish Planner 2.0 公開・引継ぎ

2026-09-12 / PCS-APP-0002 / PCSAPO / マキシ企画

## 今回の実装

既存のExpoアプリと大会カタログを継続利用し、事前計画と早見カードを中心に再構成した。目的別の目標設定、6種類の配分、任意の区間ペース、コース補正、停止、正確な関門判定、カード、保存を単一の計算結果につないだ。

- 画面は「計画・大会・カード・保存」。練習スコア、走行中操作の導線を外した。オープニングは2.0.1で復元した。
- 制限完走では関門余裕を表示。記録目標では任意表示。非表示でも登録した正式締切の超過は通知する。
- 5分・10分の配分は前後半の総所要時間差。停止時間を含む。補正は独立した設定。
- 締切逆算は全正式関門とフィニッシュに希望余裕を残す。最速許容条件で成立しなければエラー。参考・勧告時刻は警告だけに使用。
- 2.0.2ではフルの主要11地点を1枚に固定。関門・停止・補正は任意の別紙に整理。比較カードは任意の3目標を同じ配分・コース条件で再計算する。
- 出力時の設定とHTMLを保存。旧版原文は残す。旧手動ラップは意味が曖昧なため自動変換しない。
- 保存は2世代の検証付き書込み、直列キュー、別画面からの古い更新検出。バックアップ復元前に現在データを退避する。

## 検証コマンド

Node 24、pnpm 11.19.0。依存はロックファイルを使用する。

```sh
pnpm install --frozen-lockfile
pnpm test
pnpm typecheck
pnpm run build:web
pnpm run build:ios:bundle
```

iOS用プログラムの書き出し成功は、署名付きiPhoneアプリの動作確認やApp Store審査通過を意味しない。

## リリースを戻す場合

Git履歴を強制的に書き換えない。公開した変更を新しいrevertコミットで戻し、Pagesの成功と公開URLを確認する。SDK更新前のソースはビルド依存が不完全だったため、単純なソース巻戻しでは旧ビルドが失敗する可能性がある。緊急時には最後に成功したPages配布物を確認する。

新版は旧保存キーを削除しない。旧版への戻しでは新版で追加した計画は表示できないため、必ず新版のJSONバックアップを先に保管する。新版データを旧形式で上書きしない。

## 販売前の残作業

[App Store準備](AppStore準備.md)を参照。価格、課金方式、販売契約は今回決定しない。

- 実機での文字拡大・読み上げ、PDF共有、機内モード、アプリ終了・復元の確認。
- 紙への100%印刷、手首に装着して汗・光・揺れの条件で判読試験。
- 全国のひな型を最新確認済みデータとして販売しない。発売対象の大会・年度の正式要項と項目を点検する。
- 3案は同じ条件の目標タイム比較。異なる補給・配分を持つ保存済み3計画の横並び比較、公式データ更新差分の自動適用は今後の拡張。
- 現在の版は任意距離の手入力を継続する。フル専用に既存データを制限しない。
- 2.0.2ではHTMLカードを実寸指定し、アプリ内にも同じHTMLのA4用紙プレビューを表示。物理的な画面サイズは端末ごとに異なるため実寸を保証しない。
