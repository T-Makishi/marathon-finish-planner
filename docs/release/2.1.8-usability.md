# 2.1.8 操作・印刷の改善と旧データ整理
PCSAPO / マキシ企画

## 設計
1. 携帯カードに登録関門を常時表示する。標準距離と関門距離を統合し、同距離は1行にする。締切は時刻（翌日区別）、累計は選択されたネット/号砲基準。関門行の追加高さを加味してページ分割し、二つ折りの表裏を同じ地点に揃える。詳細関門表の別紙指定は維持。
2. 本番の大きな完走タイムの右隣に別基準のタイムを配置し、表見出しへの重なりを解消。
3. 移行案内のパネル・確認必須による印刷ブロックを廃止。現在の計画を保持して、旧原文アーカイブ、不要な印刷履歴、機械的な移行名称・備考を清掃。オープニング画像は現行設定へ先に移す。旧形式だけの端末にも一度読み込み変換して現行形式で検証保存してから消去する。
4. 旧データ削除は現行保存スロット2個の書き戻し確認後に限定。書き込み失敗時は旧データを消さない。復元前バックアップも清掃して旧原文が再膨張しないようにする。利用者の現在の計画・削除済み計画は維持。
5. 新規機能の提案より、作成→保存→カード出力→復元の使い勝手検証を優先する。

## 実装・検証結果
- 関門の太字表示、ネット時間の右配置、関門追加に応じたカード分割を実装。
- 未使用の旧練習機能・試作画面など10ファイルを削除。旧形式の変換処理は未更新端末の計画を保持するため継続。
- 自動テスト81件成功、TypeScript検査成功、Web・iOS向けエクスポート成功。
- ブラウザーで都道府県絞り込み→尚巴志の計画作成→保存→目標入力→カード作成→再読み込みによる設定保持を確認。制限超過の警告も確認。
- 印刷HTMLで尚巴志13km関門11:00を表裏双方に確認。ハーフ・フルのカード内に文字のはみ出しがなく、表と下部ペース説明が重ならないことを寸法測定で確認。
- 保存失敗時の旧データ保持、両保存スロットの清掃、復元前データの清掃、現行計画とオープニング画像の保持を自動テストで確認。
- 実機印刷・iPhone実機操作・App Store審査は今回の確認範囲外。Web公開の反映は公開後に別途確認する。
- 軽量化は旧保存データと未使用ソースが対象。Web配信バンドルの縮小を保証する変更ではない。
