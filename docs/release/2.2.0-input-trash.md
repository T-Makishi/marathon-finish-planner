# 2.2.0 入力支援と削除済み計画の管理
PCSAPO / マキシ企画

## 設計
- 保存画面の削除済み計画に個別・一括の完全削除を追加。確認画面で対象と復元できないことを表示する。現在利用中の計画は削除対象外。
- 削除を保存して成功後に完了表示。2つの保存スロットとアプリ内復元前コピーから対象を除去する。外部バックアップには影響しない。
- 時刻、所要時間、ペース、秒数・分数の入力を共通化。全角数字・コロン・小数点・マイナス記号を半角化する。
- 手入力を残し、選択ボタンで数字選択を展開。時刻は0〜23時、所要時間は0〜99時、分秒は0〜59、ペースは0〜99分。単位入力はよく使う値と現在値を選択でき、それ以外は手入力可能。
- デザインの全面改修は3案の提案にとどめ、今回の機能改善だけ公開する。

## 検証結果
- 自動テスト87件、TypeScript検査成功。全角・符号・小数の変換、個別・一括削除、現行計画の保護、2保存スロットと復元前コピーからの除去、保存失敗時の通知を確認。
- ブラウザーで全角入力が02:50:00に変換され、分の選択で02:45:00へ変わることを確認。個別・一括削除の対象表示とキャンセルを確認。永久削除処理は隔離した保存テストで実施し、実ブラウザーの計画は消去していない。
- Web・iOS向けビルド成功。実機iPhoneでの操作は未検証。
- 現在の公開アプリに更新。元の作業フォルダー、管理台帳、Drive、Obsidianへの変更なし。全面デザイン変更は未実装。
