# 2.1.3 日付のカレンダー選択

PCSAPO / マキシ企画

## 設計
- 対象は「開催日」「要項を確認した日（任意）」。共通 DateField で月別カレンダーを開く。
- 年月移動、日曜日始まりの7列、選択日の強調、今日の月への移動、未設定に戻す操作、キャンセルを備える。
- 選択した日だけ確定し、月移動やキャンセルでは既存値を変更しない。画面は日本語年月日、保存値は従来の YYYY-MM-DD。
- 初期表示月は保存済みの有効な日付、未設定・不正な旧データの場合は端末の今月。不正な旧データは元の値を表示し、選択するまで上書きしない。
- Web / iOS 共通のモーダルを使用。日付ボタンに完全な日付の読み上げ名、選択状態を付ける。端末の戻る操作でキャンセル。
- 暦の計算は時刻・タイムゾーンに依存しない。月末、閏年、年跨ぎを確認する。
- 印刷レイアウト、ペース計算、大会データは変更しない。
