# 2.1.7 コース編集の折りたたみと保存
PCSAPO / マキシ企画

## 設計
関門・停止・補正の3項目を独立した折りたたみにし、初期状態は閉じる。見出しには登録件数、補正には適用ON/OFFも併記。開閉は表示状態だけで入力内容を変更しない。別の計画に切り替えたら閉じる。計画画面の「区間ごとの補正を設定」から来た場合は補正を開く。

「この計画を保存」を削除操作の直前に配置し、すぐ下に保存状態を表示。既存の自動保存は維持。手動保存は既存の直列化・書き戻し確認付き保存処理を利用し、成功時に時刻付き完了表示、失敗時は同じ場所にエラー。保存中に編集された場合、古い内容の成功を最新内容の成功として表示しない。入力が変わったら完了メッセージは消す。削除は従来通り確認後に復元可能な削除済み一覧へ移す。
