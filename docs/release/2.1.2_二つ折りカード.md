# 2.1.2 二つ折りカード設計

2026-09-12 / PCSAPO / マキシ企画

- 対象は「本番案＋3案比較」。表面を本番案、裏面を3目標比較とする。
- 2面を隙間なく横につなぎ、170×135mmの外周だけを切り取り線とする。中央85mmに実線の折り線を重ね、「折り線・切らない」と明記。
- 印刷面を外側にして山折りし、85×135mmで携帯する。両面印刷は不要。
- 面内の余白4mmを維持し、文字・時刻を中央線に重ねない。カード面自体の枠線は除去し、外周1本と中央折り線だけにする。
- 多区間の場合は、本番案と比較表の同じ区間を組にして各ページに配置。物理カード枚数は2面を1枚として数える。
- 単独の本番案・比較表は従来どおり1面カード。保存値、タイム計算、印刷倍率は維持。
- 関門確認表の締切時刻を太字にする。
- 検証：通常・比較のみ・二つ折り・長距離の組み合わせ、外周と中央線、実寸、印刷HTMLと画面の表示。

## 検証結果
- 自動検証73/73、型チェック、Webビルドを通過。
- ブラウザで外周170×135mm、中央位置85mm、2面の隙間0、面ごとの境界線なしを確認。
- 外周は破線、中央は実線。表・裏とも横方向のはみ出し、時刻表とフッターの重なりなし。
- 関門確認表の締切時刻の太さ750を確認。
- 紙の実物を折る試験は未実施。A4・100%で印刷し、50mm目盛りを実測する。
