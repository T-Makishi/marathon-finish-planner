# 2.1.0 構成変更の設計

2026-09-12 / PCSAPO / マキシ企画

## 操作設計
- 上部と初期表示を大会→計画→カード→保存とする。
- 保存内に設定を設置。端末のJPEG/PNG画像を選択、縮小保存、次回起動へ反映、プレビュー、標準へ復帰。画像は外部送信しない。
- 旧カード出力履歴の常設表示と自動蓄積を終了。旧履歴と移行原文は既存バックアップ互換性のため保持し、独立パネルを廃止。
- 不具合問い合わせの画面ボタン・公開GitHub Issuesへの誘導を取り除く。プライバシーとバックアップは維持。
- 大会選択は47都道府県のプルダウン、ハーフ・フル・ウルトラの種別、名称検索、件数表示。名称行を押して詳細を展開し、選択操作で計画に追加。保存済み計画一覧も折りたたむ。

## 保存設計
- schemaVersion 2の後方互換なoptional settingsを追加。画像は検証済みJPEG/PNGのdata URIに限定し、バックアップにも含める。
- 元画像は端末のファイル選択経由。最大10MB、最長辺1600pxへ縮小、JPEG化、新規画像は約512KB以下（data URI 70万文字以内）、互換読み込み上限2MB。破損・キャンセル・保存失敗は従来の画像を保持。
- 未設定は旧画像設定を引き継ぎ、明示的なnullは標準画像。保存リポジトリの世代保護と復元確認を継続。

## 大会情報設計
- 主催者の公式ページから名称・開催地・種目距離・年度を確認する。確認できた開催日、スタート、制限時間のみ追加。関門が不明なら未登録。
- 新規情報は出典と確認日を保持。年度の異なる大会、未確認データ、未収録を区別する。全国全大会の網羅は保証しない。
- 複数距離を持つ大会は種目ごとの選択を可能にする。既存データの重複を検出する。
- 未確認のスタート時刻を09:00と仮定しない。新規選択時は空欄として入力を要求する。

- ウェーブ別に同じ制限時間が設定される大会は参加区分の開始時刻を選択して取り込む。第1ウェーブ基準の大会は号砲時刻を維持し、自分のウェーブ時刻を計画で指定する。

## 検証
- 設定の後方互換、画像入力検証とバックアップ往復、既存計算・保存検証。
- 大会フィルタ、47都道府県、距離種別、重複ID、公式URL、空の結果、折りたたみと選択。
- Web画面・画像変更と標準復帰・再起動、Web/iOSビルド。公開処理と配布バージョン確認。
