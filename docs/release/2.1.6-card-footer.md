# 2.1.6 カード下部の可読性
PCSAPO / マキシ企画

## 設計
- 本番カードに配分名と移動平均を14pt・750、比較カードは配分名・3目標の移動平均を11pt・750で表示。それぞれ表内の累計時間と同じ文字サイズと太さ。
- 比較カードに本番計画の平均をコピーしない。挑戦・本命・堅実の計算結果から個別に表示。
- コース補正は「未設定」「OFF」「ON」を両面に表示。自動で標高を秒数へ変換する機能ではない。
- 用紙寸法と折り線は維持。下部の文字を大きくするため上部余白を減らし、1枚11地点まで・表の行高5.5mmにする。ウルトラは従来通り分割し表裏の地点を一致させる。リストバンドは12地点、行高6.5mmとし、狭い幅の折り返しを確保する。
- 制限完走で実際には適用されない前後半差を本番カード下部に表示しない。

## 高低差の挙動確認
既存の計算テストで、補正ONによる区間ペース変更、目標維持時の再配分、他区間維持時の到着時刻変更を確認。尚巴志は厳密な坂の区間境界・利用者の補正時間が未設定であり、説明から架空の補正を生成しない。

## 検証結果
- 78/78自動テスト、型検査、Webビルド成功。
- ブラウザーで本番の累計時間・下部文字18.6667px（14pt）、比較14.6667px（11pt）、太さ750の一致を確認。
- フル11地点で表と下部の隙間は本番29.66px、比較5.09px。ウルトラ分割後も重なりなし、細幅カードも横・縦はみ出しなし。
- 既存の目標維持・固定基準の高低差補正テスト成功。平均は計算結果を個別使用。
- 印刷用HTMLで確認。実紙印刷・iOS実機は未検証。
- 既存個人計画、台帳、Drive、Obsidianは変更なし。
