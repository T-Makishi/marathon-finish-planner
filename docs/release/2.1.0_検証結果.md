# 2.1.0 構成変更・大会情報の検証

2026-09-12 / PCSAPO / マキシ企画

## 変更
- 大会→計画→カード→保存の順序。初期表示も大会。
- 保存内に画像設定。画像選択、端末内で縮小・JPEG変換、保存後に反映、標準復帰、再表示。
- 出力履歴パネル・移行原文パネル・問い合わせ誘導を削除。旧データはバックアップ互換のため保持。印刷時の履歴増加を停止。
- 大会選択に47都道府県・距離種別のプルダウン、名称検索、折りたたみ詳細。保存済み計画も折りたたみ。
- 17大会31種目を追加。合計134種目（フル63、ハーフ44、ウルトラ27）。新規登録関門39地点。
- 不明な開始時刻の09:00補完を廃止。ウェーブ別の選択と、経過時間形式の関門取り込み（日付をまたぐ場合を含む）に対応。

## 確認結果
- 自動検証71/71通過。既存計算・印刷・保存の62件と、新規9件。
- 型チェック、Webビルド、iOS Hermesバンドル書き出し成功。
- Web実操作：初期タブ、大会選択、京都府＋ウルトラの2件への絞り込み、丹後100kmの04:40選択→14時間制限の取り込みを確認。
- Web実操作：JPEG化した画像が保存・再読込後も残ること、画像の読込完了、オープニングへの実反映、標準画像への復帰を確認。
- 画像保存失敗時の旧データ保持、外部URL・壊れた設定・過大画像の拒否、画像を含むバックアップ往復を自動検証。
- 表示された大会一覧を目視確認。大きな大会カードを名称と距離のコンパクトな行へ変更。
- iPhone/iPad実機・ネイティブ画像選択は未検証。App Store公開済みではない。
