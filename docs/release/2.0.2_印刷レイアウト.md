# 2.0.2 印刷レイアウトの整理

2026-09-12 / PCSAPO / マキシ企画

## 修正対象

提供されたNAHAマラソンの2種類のPDFを全ページ確認。カード幅の混在、主要11地点の8行＋3行への分割、比較カードだけが次ページに残る配置、ネットの見出しと号砲基準の表の不一致を修正する。

## 設計と仕様

- 選択順はカード種類、サイズ・時間基準、追加資料、A4プレビュー、出力。
- ポケット85×135mm。1案または比較3案。両方なら同じ大きさの2枚をA4の1ページに並べる。
- 手首用50×180mmは1案専用。フルの11地点は分割しない。
- 比較を含む既存の手首設定は、説明を表示してポケットで出力。保存データは勝手に削除しない。
- 関門、停止、補正の設定は各々任意の別紙。空の補給・補正ページは作らない。多数の関門は見出しを繰り返して改ページする。
- 見出し、比較列の目標、ゴール行は印刷の時間基準を統一。入力の目標値は変更しない。
- 比較目標を現在の目標±5分にそろえる操作を追加。選択するまで既存比較値は保持。
- プレビューと出力は同じHTMLを使用。プレビューで前後ページと拡大を確認できる。
- A4、100%、印刷ヘッダー・フッターOFF、50mm実寸確認線と切り取り線。
- iOSのPDF生成にもA4と余白0を明示。既存オープニングを維持。

## 確認結果と限界

- 自動検証62/62、型チェック、Web書出し、iOS用書出し成功。
- ブラウザで本番＋比較の11行と同じ寸法、手首用の全11行、A4プレビューの切替・拡大を確認。
- 手首用のDOM実測は約50×180mm。追加資料24関門を3ページに分けて全件保持し、表がフッターと重ならないことを確認。
- 実際のChrome PDF保存は利用中のブラウザ操作と競合し完了していない。画面検証とPDF保存完了を同一視しない。
- 紙への印刷、手首への装着、iPhone実機のPDF共有は未確認。販売前の実機試験に残す。
